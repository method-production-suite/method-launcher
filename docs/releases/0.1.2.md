# Method Launcher 0.1.2

The launcher now installs and updates your apps on Windows and Linux as well as macOS, runs
on Intel Macs as well as Apple silicon, and keeps itself up to date on the Mac.

## Every Mac

- **One download for every Mac.** The launcher's Mac download now runs natively on Intel and
  Apple silicon.
- **Apps are checked for your Mac's chip.** Before anything is copied, the launcher checks
  that the app has code for the chip in your Mac. If a version of an app only runs on Apple
  silicon and your Mac has an Intel chip, the launcher says so and offers nothing to install.

## Windows and Linux

- **Install and update from the launcher.** On Windows and Linux the launcher now downloads
  an app, checks it against the release's published checksums, and installs or updates it,
  the same way it does on the Mac. If a check fails, nothing is installed.

## The launcher updates itself

- **Updates on the Mac.** When a new version of the launcher is out, it downloads it in the
  background, checks its signature, and offers Restart to Update. Help has Check for
  Updates and a switch to check automatically.

## Not there yet

- On Windows and Linux the launcher doesn't update itself yet. When a new version is out, it
  says so at the top of its window, with a link to the download.
- Apps released before their universal builds run only on Apple silicon Macs. Their next
  releases run on Intel Macs too.
