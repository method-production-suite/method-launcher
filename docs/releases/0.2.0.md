# Method Launcher 0.2.0

The launcher now has Settings, a full Help menu and a way to cancel an install, says
exactly what went wrong when something does, installs Linux apps as system packages where
you have apt, and comes for Linux on ARM.

![Method Launcher with two updates ready and Update all at the top of the window](https://raw.githubusercontent.com/method-production-suite/method-launcher/v0.2.0/assets/screens/updates-light.png)

## Settings

- **Where new apps go on a Mac.** Install into Applications, or into your own Applications
  folder, which needs no administrator password. An update still goes where the app is.
- **AppImage or system package on Linux.** Where you have apt, choose the system package
  (.deb): it asks for your password once and lets apt add what the app needs. An update goes
  the way the app is installed now.
- **One switch for update checks**, the same as in the Help menu. Open Settings from its
  button beside Help, or with ⌘, (Ctrl+, on Windows and Linux).

## Installing

- **Cancel.** While an install is waiting, finding the release, downloading or checking,
  its card has Cancel. Nothing is changed.
- **Plain answers when something goes wrong.** The card tells being offline apart from
  GitHub not answering, says when a release has no download for your system, when the disk
  is too full (and how much room the app needs), and on Linux when FUSE is missing, with a
  link to how to add it. A release that can't be checked links its release page.
- **Leftovers are cleaned up** on every system, if the launcher was quit in the middle of an
  install.
- **New versions every six hours.** With update checks on, the launcher looks again every
  six hours while it stays open.

## Help

- **About, User Guide, Keyboard Shortcuts, and Licenses and Notices**, beside What's New and
  Check for Updates.
- **Report a Bug** opens a new report in your browser with only the launcher's version and
  your system filled in. Nothing is sent until you submit it.

## Linux on ARM

- **The launcher itself** now comes as a .deb and an AppImage for ARM. The suite's apps have
  no Linux ARM builds yet, so there the launcher shows them and links how to build them.

## Not there yet

- Installing and updating on Windows and Linux is built and tested automatically, not yet
  tested by a person on those systems.
- The Windows installer is not signed yet, so Windows may warn you before it opens.
- "Open the launcher when I log in" is not built yet.
