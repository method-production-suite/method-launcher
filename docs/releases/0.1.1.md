# Method Launcher 0.1.1

New Method apps and first releases now show up in the launcher on their own: it asks each
app's releases, and the suite's list of apps, every time it checks, instead of knowing only
what it was built with.

## Every release, as soon as it is out

- **Method Storyteller can be installed.** Its first release, 0.2.0, is offered like the
  other apps: one click, checked before anything is copied.
- **First releases appear without a new launcher.** Whether an app has a release, and
  whether that release has a download for your computer, is read from the release itself
  when the launcher opens and when you press Refresh.
- **New apps appear too.** The launcher reads the suite's list of apps from
  methodproduction.com, checks every entry, and keeps the list it has if anything looks
  wrong or the site can't be reached.

## Not there yet

- Installing and updating from the launcher works on macOS. On Windows and Linux the
  launcher shows your apps and their versions, and links each app's download page.
- The launcher doesn't update itself yet; when a new version is out, it says so at the top
  of its window, with a link to the download.
