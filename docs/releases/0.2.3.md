# Method Launcher 0.2.3

A safer install for each Method app, and a launcher that stays light when you leave it open.

## Safer installs

- **Each app's own signature is checked.** Before installing or updating an app, the launcher
  checks that its list of checksums carries a signature from that app's own key, and refuses
  the download if the signature is wrong. For Method Reader and Method Schedule, a release with
  no signature at all is refused too, since both always sign.

## New on the cards

- **Open Sample.** An installed app that comes with a sample file shows Open Sample on its
  card, so you can see it working before you open your own work.

## Fixed

- **No slow growth when left open.** The launcher looked at the suite's list of apps again on
  every check for new releases and kept another copy each time. It now keeps one.
- **Security updates** to the parts the launcher is built from.

## Not there yet

- Installing and updating on Windows and Linux is built and tested automatically, not yet
  tested by a person on those systems.
- **The Windows installer.** Not signed, and no certificate is planned: Windows warns that the publisher is unknown before it opens.
