# Method Launcher 0.2.1

A security update to how the launcher checks its own updates, and one new setting.

## Safer updates

- **The launcher's own update checks trust only current certificates.** The part of the
  launcher that downloads its own updates now refuses certificates from authorities that have
  been distrusted. The apps' downloads were never affected: the launcher fetches them with
  your system's own tools.

## Settings

- **Open the launcher when I log in.** Off at first, and it needs no administrator password.

## Not there yet

- Installing and updating on Windows and Linux is built and tested automatically, not yet
  tested by a person on those systems.
- The Windows installer is not signed yet, so Windows may warn you before it opens.
