# Method Launcher 0.2.2

Small fixes: opening at login keeps working after you move the launcher, Linux asks for a
password with a clear reason, and a safer clipboard on Windows.

## Fixed

- **Open at login follows the launcher.** If you move the launcher, or replace it with a
  newer download under another name, it still opens when you log in.
- **A clearer password prompt on Linux.** When the launcher installs an app's system
  package, the prompt now says it needs an administrator's password to install a Method
  app, instead of naming a system program.
- **A safer clipboard on Windows.** The part of the launcher's window toolkit that reads the
  clipboard now checks the size of what it reads.

## Not there yet

- Installing and updating on Windows and Linux is built and tested automatically, not yet
  tested by a person on those systems.
- The Windows installer is not signed yet, so Windows may warn you before it opens.
