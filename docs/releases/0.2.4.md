# Method Launcher 0.2.4

Every Method app's download is now checked against its own signature before it installs, and
the launcher's own updates are checked the same careful way.

## Safer installs

- **Each app's signature is required.** Before installing or updating Method Storyteller,
  Method Reader, Method Schedule or Method Budget, the launcher checks that the release's list
  of checksums is signed with that app's own key, and refuses a release with no signature or
  no list at all.
- **Installing into a folder that needs an administrator.** When the launcher asks for your
  password to install an app, the copy that goes in place is checked again after the password,
  and belongs to the system, not to your account, as anything an administrator installs does.
- **On Linux, the system package step installs only the Method app it was asked for.**

## Safer updates of the launcher itself

- **Signed by the same developer.** An update replaces the launcher only when its code
  signature comes from the same developer as the copy you have.
- **No going back.** Once a version has been offered and checked, an older one is never
  installed in its place.
- **If the update needs your password,** the new copy is checked again before it goes in, and
  belongs to the system.

## Fixed

- **The ⌘ in Keyboard Shortcuts.** On a Mac, the shortcut for Refresh drew as an empty box. It
  shows ⌘R now.

## Not there yet

- Installing and updating on Windows and Linux is built and tested automatically, including
  a real install on Linux each week, not yet tested by a person on those systems.
- **The Windows installer.** Not signed, and no certificate is planned: Windows warns that the publisher is unknown before it opens.
