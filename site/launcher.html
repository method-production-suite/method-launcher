Method Launcher

Every app, one download.

The front door to the Method Production Suite. See every app, install the ones you want, keep them up to date and open them, from one small window.

Download for Mac Windows and Linux

What it does

  • Install with one click. Each app comes from its own latest release, checked before anything is copied.
  • Updates in one place. See which apps have a new version, then update one or all of them. It asks before it quits an app you have open, and looks again every six hours while it is open.
  • Your recent files, across the suite. Scripts, schedules and budgets you opened lately, each opening in the app it belongs to.
  • Demo the suite. Opens your installed apps on Field Station, an invented production, so you can see how they fit together before you use your own work.

How it checks a download

Nothing runs until it passes. On a Mac, every app must be signed by the suite's Developer ID, notarised, and have code for your Mac's chip. On Windows and Linux, every download must match the checksum its release publishes. If a check fails, nothing is installed, and the card says why in one sentence. You can cancel while it downloads.

Platforms

macOS (Intel and Apple silicon), Windows (x64) and Linux (x86_64 and ARM). On a Mac it installs into Applications, or into your own Applications folder with no password, and keeps itself up to date. On Linux it installs each app's AppImage, or its system package where you have apt. Installing on Windows and Linux is built and tested automatically, not yet tested by a person on those systems. The Windows installer is not signed yet, so Windows may warn you before it opens. The suite's apps have no Linux ARM builds yet; there the launcher shows them and links how to build them.

Private by default

No account, no server of its own and no tracking. It reads the suite's list of apps from this site and each app's releases from GitHub, and you can turn update checks off. It never changes your files.

Free and open source

MIT or Apache-2.0, like every Method app. The code is on GitHub.
